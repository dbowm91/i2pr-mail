# Milestone Implementation Plans

Implementation plans are bounded handoffs tied to a repository baseline. They may be corrected or superseded without rewriting canonical direction.

Required structure:

1. Objective
2. Why this milestone is ready
3. Current implementation evidence
4. Invariants that must not regress
5. Scope
6. Required production changes
7. Ordered work packages
8. Failure, cancellation, restart, and contention semantics
9. Compatibility and migration
10. Required tests
11. Required verification commands
12. Documentation updates
13. Acceptance criteria
14. Stop conditions
15. Closure evidence required
16. Handoff notes

Corrective work receives a new numbered plan in the same subsystem.
