# Subsystem Roadmaps

A subsystem roadmap owns one coherent workstream across several implementation milestones.

Required structure:

1. Purpose and ownership boundary
2. Work classification
3. Non-goals
4. Current state
5. Target architecture
6. Dependency graph
7. Milestones
8. Cross-cutting requirements
9. Verification strategy
10. Risks and decision points
11. Completion definition
12. Milestone status table

Roadmaps remain at subsystem level. Commit-specific mechanics belong in plans/implementation/.
