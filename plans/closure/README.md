# Closure and Verification Records

Closure records decide whether implementation milestones actually completed.

Path: plans/closure/<subsystem>/NNN-status.md

Required sections:

1. Executive finding
2. Requirement-to-evidence matrix
3. Production implementation evidence
4. Verification executed
5. Invariant review
6. Failure and recovery review
7. Migration and compatibility review
8. Security review
9. Documentation and operations
10. Unresolved findings with severity
11. Roadmap disposition
12. Registry updates

A milestone cannot close on compilation/formatting alone, with an unimplemented security/recovery requirement, with missing required tests absent justified substitute evidence, or with known high/medium correctness findings. Conditional closure must name the missing external/operational evidence precisely.
